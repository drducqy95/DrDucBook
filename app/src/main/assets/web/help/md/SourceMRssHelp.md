# Hướng dẫn nguồn RSS

Nguồn RSS dùng để đọc tin, bài viết hoặc feed theo định dạng RSS/Atom/API.

## Trường thường dùng

- Tên nguồn.
- URL feed.
- Rule danh sách bài.
- Rule tiêu đề.
- Rule thời gian.
- Rule ảnh.
- Rule mô tả.
- Rule nội dung.

## Kiểm tra nguồn RSS

1. Mở URL feed trên trình duyệt hoặc gỡ lỗi nguồn.
2. Xác định dữ liệu là XML, HTML hay JSON.
3. Chọn rule phù hợp.
4. Kiểm tra từng item có URL chi tiết không.

## Lỗi thường gặp

- Feed cần User-Agent riêng.
- URL ảnh nằm trong field phụ.
- Nội dung đầy đủ không nằm trong feed mà phải mở trang chi tiết.
- Feed giới hạn số bài, cần phân trang hoặc endpoint khác.
