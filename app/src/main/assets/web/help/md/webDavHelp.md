# WebDAV

WebDAV dùng để sao lưu, khôi phục và đồng bộ một số dữ liệu qua server cá nhân hoặc dịch vụ lưu trữ hỗ trợ WebDAV.

## Cấu hình cần có

- Địa chỉ server WebDAV.
- Tài khoản.
- Mật khẩu hoặc app password.
- Thư mục sao lưu nếu muốn tách dữ liệu app.

## Sao lưu

Dữ liệu sao lưu có thể gồm:

- Giá sách và tiến độ đọc.
- Nguồn sách, nguồn RSS.
- Rule thay thế.
- Cài đặt app.
- Một số cấu hình dịch và đọc.

## Khôi phục

Khi khôi phục sang máy mới:

1. Cài app.
2. Nhập cấu hình WebDAV.
3. Chọn bản sao lưu cần khôi phục.
4. Khởi động lại app nếu được yêu cầu.
5. Kiểm tra lại quyền lưu trữ, đường dẫn cache và nguồn sách.

## Lỗi thường gặp

- Sai URL server hoặc thiếu dấu `/` cuối.
- Dùng mật khẩu tài khoản thay vì app password.
- Server giới hạn dung lượng.
- Mạng chặn kết nối WebDAV.
- File sao lưu cũ không tương thích hoàn toàn với bản app hiện tại.
