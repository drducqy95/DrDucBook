# Sách WebDAV

Sách WebDAV cho phép lưu sách cục bộ hoặc file xuất ra lên server WebDAV để dùng lại trên thiết bị khác.

## Tải sách lên

Có thể tải sách lên từ:

- Màn thông tin sách.
- Màn cache hoặc xuất ebook.
- Trình quản lý file nếu app có tùy chọn chia sẻ.

## Tải sách xuống

Trong màn WebDAV Book, chọn file cần dùng rồi thêm vào giá sách hoặc tải về thiết bị. Với sách lớn, nên dùng mạng ổn định.

## Lưu ý

- Tên file nên tránh ký tự đặc biệt quá lạ để đồng bộ tốt hơn.
- Nếu sách có nhiều ảnh, dung lượng upload có thể lớn.
- Không xóa bản cục bộ trước khi kiểm tra file trên WebDAV đã mở được.
- Nếu upload lỗi giữa chừng, xóa file lỗi trên server rồi upload lại.
