# Welcome to DrDucBook 1.0

DrDucBook 1.0 is the first release under the DrDucBook identity, built on the open-source Legado and legado-with-MD3 projects.

## Reading sources and content

- Supports Legado book sources and compatible VBook plugins.
- Supports text novels, comics, audiobooks, and media content.
- Adds per-source browser sign-in, CAPTCHA/Cloudflare handling, and cookie persistence.
- Improves JavaScript execution and VBook plugin compatibility.
- Adds VBook registry and plugin import, inspection, and management.

## Accounts and synchronization

- Sign up and sign in with email or Google.
- Free, Premium, and Admin account roles.
- Backup, restore, and synchronization through Supabase or Google Drive.
- Password changes and Admin-only account access management.

## Ebook and authoring

- Fixes ebook export and remembers the selected export folder.
- Adds ebook editing and a staged authoring workflow from idea and outline to volumes and chapters.

## AI, translation, and speech

- Expands AI Router with API keys, OAuth, connection tests, provider model discovery, and fallback routes.
- Adds a floating PiP AI chat and tools for creating Legado and VBook source plugins.
- Improves offline Chinese-Vietnamese Quick Translation grammar.
- Manages TTS and local models according to account access.

## Notice

DrDucBook does not provide or host content sources. Users are responsible for the sources, accounts, and data they add. Back up your data before updating or changing devices.
